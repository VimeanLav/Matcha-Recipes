# Matcha Recipes

Monorepo for the Matcha Recipes project.

## Structure

- `backend/` - API or server-side code
- `frontend/` - Flutter app

## Frontend

The Flutter app lives in `frontend/`.

```bash
cd frontend
flutter pub get
flutter run
```

## Backend

The backend folder is reserved for the API/service layer.

## Notes

- Keep shared documentation at the repository root.
- Keep app-specific configuration inside each project folder.
